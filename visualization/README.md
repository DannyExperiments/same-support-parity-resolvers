# Offline explorer

Extract the two files to the same directory and open index.html in a browser. It runs offline with no external downloads. Select a block length and a resolver. Each colored bar is an expected occurrence count across the selected group, and the exact counts appear below the canvas. The rotation slider turns the same geometry.

The separating input begins with #, then uses 2ⁿ copies of aⁿ# for every positive integer n, in order. The sum of the uniform priority 2 counts is one. The sum of the priority 1 counts diverges.
