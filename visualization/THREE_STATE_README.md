# Three-state parity explorer

Extract the two files together and open index.html. Select a block length and switch between the weighted and uniform resolvers. Both bars are expected counts in a single group of 2ⁿ blocks. The y scale adapts to the block length but stays fixed when switching between the two resolvers.

Under the weighted resolver both priorities have equal expected counts. Under the uniform resolver, the priority 2 counts sum to one across the groups, while the priority 1 counts sum to infinity. The rotation control turns the view.
